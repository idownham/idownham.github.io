# idownham.github.io

Personal portfolio site for Ian Downham — Supply Chain Management, University of Arkansas.

Built for Module 2: AI-Assisted Personal Portfolio Design.

## Structure

| Path | What it is |
|---|---|
| `index.html` | Portfolio homepage |
| `links.html` | Mobile-first Linktree-style page |
| `baseline/` | **Week 1 artifact.** The generic output from the bare prompt "Build me a portfolio page based on my resume" with no other direction. Preserved unedited as a comparison piece — this is what the project is deliberately moving away from. |

## Process

Commit history is intentional documentation. Each commit records one step of the
progression from unguided AI output to a directed, personal design.

Live at https://idownham.github.io

## A note on `baseline/`

`baseline/` holds the unedited output of a single unguided prompt, kept deliberately
as a comparison artifact for the assignment. It is **not** representative of this
site's design or of my work. It carries a `noindex` tag and is excluded in
`robots.txt` so it does not surface in search results.

## Privacy

No phone number appears anywhere in this repository, in its history, or on the
live site — that was a deliberate choice, since the repo is public and anything
committed to a public repo is permanent. Contact is by email or LinkedIn.

No credentials, tokens or keys are stored here. The site is static: no forms,
no analytics, no cookies, no third-party scripts.
